# PdfShrink — PDF を小さく

実行ファイルのダウンロード.
https://github.com/k518-2026/PdfShrink/releases

PDF の中の画像を JPEG で圧縮し直して、ファイルを小さくする Windows アプリです。
PDF をウィンドウにドラッグ＆ドロップ（複数可）するだけで、元のファイルと同じフォルダーに
`名前_compressed.pdf` を作ります。元のファイルは変更しません。

2026-11-02 に PDFTools（C++ / MuPDF）と PDFTools2（.NET Framework / iText）を置き換えるために作りました。
元のソースは `E:\ClaudeCode\_archive\merged-2026-11-02\src\` にあります。

## 使い方

1. PdfShrink.exe を起動する
2. 「画像の画質」（10〜100、既定 60）と「画像の大きさ」（既定は長辺 2000 ピクセルまで）を選ぶ
3. PDF をウィンドウにドラッグ＆ドロップする（「ファイルを選ぶ…」でも可。フォルダーを落とすと中の PDF をまとめて処理）
4. 一覧に圧縮前・圧縮後のサイズと削減率が出る。行をダブルクリックすると保存先のフォルダーが開く

exe に PDF を渡して起動しても（「送る」メニューなど）同じように処理します。

## 何をしているか

- ページと、その中のフォーム XObject をたどって画像を探し、次のものを JPEG で圧縮し直します
  - JPEG（DCTDecode）の RGB / グレー
  - 無圧縮または Flate 圧縮の RGB / グレー（8 ビット）
- 「画像の大きさ」で長辺の上限を決めると、それより大きい画像を縮小します
- 圧縮し直しても小さくならない画像は元のままにします
- 複数のページで使い回している画像は 1 回だけ処理します
- 本文（コンテンツ ストリーム）も圧縮して保存し、使われていないオブジェクトは保存時に落とします

### 触らない画像

見た目が変わるおそれがあるものは、元のまま残します。

- CMYK・特色・インデックスカラーの画像、1 ビットの白黒画像、マスク画像
- `/Decode` や色キーマスク（`/Mask` の配列）を持つ画像、JPEG2000・JBIG2 など
- 透明度（`/SMask`）は別の画像として残るので、透明な部分は保たれます

### 開けない PDF

編集にパスワード（所有者パスワード）が必要な PDF は開けず、一覧に「失敗」と出ます。

## ライセンスの選択

PDF の読み書きには **PdfSharp 6.1.1（MIT ライセンス）** を使っています。
旧 PDFTools の MuPDF と旧 PDFTools2 の iText はどちらも AGPL で、配布するとソースの公開義務が生じるため使いませんでした。
画像の読み込みと JPEG 化は WPF（Windows 標準）のコーデックだけで行っています。

## ビルド

- .NET 8 SDK
- `dotnet build PdfShrink.slnx -c Release`
- 単一 exe の発行は AppHub で行います: `apphub release PdfShrink`

## 確認したこと（2026-11-02）

- 自作のテスト PDF（4000×3000 の JPEG、PNG、グレー、透明つき PNG、ノイズ画像、同じ画像の使い回し）: 5.9 MB → 1.7 MB（画質 60・長辺 2000）。pdftoppm で描画して元と見比べ、色・透明・グレーが保たれていることを確認
- 実際の本の PDF（99 ページ）: 23 MB → 3.8 MB、画像 19 枚すべて圧縮
- 所有者パスワード付きの PDF は「開けませんでした」と表示して止まることを確認

圧縮の結果はすべての PDF で同じとは限りません。大事な PDF は、圧縮後のファイルを開いて確かめてから使ってください。
